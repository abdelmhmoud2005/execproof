# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | yes       |

## Reporting a vulnerability

Open a private security advisory via GitHub (Security > Advisories) or email the maintainers. Do not open a public issue.

## Intended use

This tool is for authorized security testing only. Users are responsible for complying with the scope and rules of their engagements.
